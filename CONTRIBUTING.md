# Contributing

1. Open an issue with behavior, impact, and acceptance criteria.
2. Create a focused branch from `main`.
3. Add tests for changed behavior.
4. Run `npm run verify`.
5. Update API/operational docs when behavior changes.
6. Open a PR with rationale, design notes, test evidence, risks, and rollback considerations.

Never commit credentials, personal property-owner data, production dumps, or unredacted logs. Do not report checks as passing unless commands completed successfully.
